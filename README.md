# Woodcorp | Process Intelligence

Interaktive Analyseplattform fuer die Woodcorp Order-to-Cash-Prozessdaten.

## Entwicklungsgrundlage

- Datenhaltung: Supabase (PostgreSQL)
- Analyse: Auftraege und Prozessaktivitaeten, verknuepft ueber `CASE_KEY`
- UI/UX-Skill: `.agents/skills/ui-ux-pro-max/SKILL.md` (Open Source, MIT)

Die verbindliche NXT-Designsprache wird in einem separaten Schritt festgelegt.
